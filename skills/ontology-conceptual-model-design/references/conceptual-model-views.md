# 概念模型视图契约

## 推荐视图

| 视图 | 审查内容 |
|---|---|
| 概念关系图 | 核心概念和总体关联 |
| 类层级树 | 稳定的 `is-a` 继承和公共属性 |
| 属性详情 | 标识、属性、粒度、单位、时间和版本 |
| 业务分类 | 分类维度、判断条件和分类项 |
| 对象关系 | 组成、归属、影响、依赖、责任和证据关系 |
| 规则视图 | 条件、判断、结果、优先级和例外 |
| 流程与状态 | 事件触发、状态入口出口、流程步骤和回退 |
| 权限与动作 | 角色、授权、Action 输入输出、前置和效果 |
| 实例视图 | 真实或脱敏样例如何落入模型 |
| 目标与评价 | 业务目标、任务完成条件、评价口径和证据 |

## 跨视图检查

- 同一模型元素在各视图使用相同编号和名称。
- 每个关系在两端对象视图中可定位。
- 每条规则引用已定义对象、属性、状态或关系。
- 每个动作关联角色、权限、输入、输出和前置条件。
- 每项任务完成条件可以连接到可观察事实或有权角色确认。
- 孤立元素、循环继承、无出口状态和无责任动作进入问题清单。
