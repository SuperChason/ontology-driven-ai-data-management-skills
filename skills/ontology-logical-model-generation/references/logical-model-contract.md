# 逻辑本体模型契约

## 语义到逻辑元素

| 场景语义 | 逻辑表达候选 |
|---|---|
| 业务对象和概念 | OWL Class |
| 稳定 `is-a` 继承 | `rdfs:subClassOf` |
| 文本、数字、日期等属性 | Datatype Property |
| 对象之间的关系 | Object Property |
| 统一术语、同义词和分类 | SKOS Concept/Scheme |
| 数量、类型、值域和一致性约束 | SHACL Shape，必要时结合 OWL 公理 |
| 查询与统计需求 | SPARQL 模板或目标查询接口 |
| 业务规则 | 决策表、规则引擎或可选形式规则 |
| 流程和状态 | 状态模型、流程引擎映射或相关本体表达 |
| 权限和动作 | IAM/策略引用与 Action 契约，可选 ODRL 映射 |
| 目标和评价 | 目标、完成条件、指标定义及来源关系 |

## 必备元数据

- 模型和元素唯一标识
- 名称、定义和语言
- 来源语义条目和证据
- 适用场景、任务和范围
- 状态、版本、责任和更新时间
- 依赖模型和兼容范围
- 废弃与替代关系

## 生成检查

- 所有引用 URI 可解析或明确外部依赖。
- 对象属性定义域和值域符合概念模型。
- 类继承没有由组成或状态关系误建的父子关系。
- SHACL 严重级别和业务阻断等级一致。
- 查询模板声明输入、预期结果和权限。
- 动作契约只引用已确认的角色、权限、输入和状态。
