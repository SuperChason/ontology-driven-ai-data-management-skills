# 场景知识结构契约

## 来源登记字段

| 字段 | 说明 |
|---|---|
| source_id | 来源唯一编号 |
| source_type | 制度、文档、数据、接口说明、模型、案例、专家或已有语义资产 |
| title | 来源名称 |
| location | 可定位位置或访问方式 |
| authority | 法定、企业正式、部门正式、项目材料、历史案例、专家经验等 |
| owner | 来源责任人 |
| version_and_time | 版本、生效和失效时间 |
| applicable_scope | 组织、业务、场景和条件 |
| access_status | 可访问、待授权、部分可用或缺失 |
| related_tasks | 支撑的 Agent 任务 |
| extraction_status | 未提取、候选、有证据、已确认、失效 |

## 知识领域地图

只围绕当前场景建立主题和依赖，例如：

```text
场景目标
├── 业务对象与术语依据
├── 数据口径与来源依据
├── 关系和影响依据
├── 规则与例外依据
├── 过程、状态和权限依据
├── 动作与系统接口依据
└── 目标、完成条件和评价依据
```

这张图用于定位知识原料，不承担正式对象分类和概念继承建模。

## 冲突与缺口字段

- 冲突或缺口编号
- 涉及任务和候选知识
- 冲突来源或缺失证据
- 业务影响
- 是否阻断
- 待裁决角色
- 处理计划
- 当前状态
